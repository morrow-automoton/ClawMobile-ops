# Project Status Template

Use this file (or copy it into a project folder as `STATUS.md`) whenever work is mid-flight. Update the snapshot at the end of each session so we can recover quickly after resets.

## Snapshot
- **Project:** (name)
- **Owner:** (who’s driving it)
- **Last touched:** (UTC timestamp)
- **Overall state:** (e.g., Recon, In progress, Waiting, Blocked)

## Latest Progress
- Bullet list of what changed since the previous update. Include links/screens, key decisions, and anything that was explicitly deferred.

## Next 3 Actions
1. First concrete action (with owner + ETA if relevant)
2. Second action
3. Third action

## Blockers / Risks
- Note anything that might stop progress or needs input; include owner + request date.
